What is ChatLeaf?

ChatLeaf is a simple, private, and secure chat application for Android. It lets you connect with friends and family through fast, reliable messaging — with a strong focus on account security and user privacy.

Key Features

  • Secure sign-up with email verification
  • Login with email/password or Google Sign-In
  • Unique, customizable User ID for finding and connecting with others
  • New-device login alerts for account security
  • Simple, clean chat experience
